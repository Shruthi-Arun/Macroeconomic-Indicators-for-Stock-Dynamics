# Macroeconomic-Indicators-for-Stock-Dynamics
ESE 5380 Final Project

This project examines how key macroeconomic indicators influence S&P 500 returns using VAR, VECM, and ARIMA-based time-series methods. The goal is to understand both short-run market reactions and long-run relationships with economic fundamentals.

# Navigation

- **ESE5380_AGM**  
  Main project notebook with models and final output
  
- **Notebooks**  
  Contains all analytical and modeling notebooks used throughout the project.
  - **VAR**  
    Notebook implementing Vector Autoregression (VAR) modeling.
  - **VECM**  
    Notebook for Vector Error Correction Model (VECM) analysis.
  - **ARIMA**  
    Notebook covering ARIMA and SARIMA time-series forecasting models.
  - **ESE5380_Data_collection**  
    Notebook handling data cleaning, transformation, and feature preparation.
  - **EDA**  
    Notebook providing exploratory data analysis of key variables.

- **macro_data_cleaned.csv**  
  CSV containing preprocessed and cleaned datasets ready for modeling.
